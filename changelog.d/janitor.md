### Added
- `agentic-delivery/scripts/janitor.sh [--apply|--scheduled|--enable] REPO...`: unattended cleanup. A worktree is removed only on positive proof it is finished (PR MERGED at exactly the local HEAD, nothing modified for `JANITOR_IDLE_MIN` minutes, no `.lane-lock`/`.lane-heartbeat`/`git worktree lock`), re-checked right before removal. Everything not in git (a binary patch plus a tar of untracked and ignored files) is archived to a 0700 state dir and read back first; a failed archive keeps the worktree. Only allowlisted executables (dev servers, test runners, headless browsers; matched on argv0, never on a substring) whose cwd is inside a finished worktree, or that have run past `JANITOR_MAX_AGE_S` (default 2h) in a linked worktree, are killed, with cwd and start time re-checked before each signal. Dry run by default; the scheduled mode only dry-runs (plan saved to a log) until `janitor.sh --enable` is run once. Every action goes to a ledger.
- `agentic-delivery/scripts/install_janitor.sh [--uninstall|--check] [REPO...]`: idempotent 15-minute schedule (macOS LaunchAgent with a log and a Homebrew-aware PATH, Linux systemd user timer, else a printed crontab line) with per-consumer escaping; repos accumulate in a list file; `--check` reports a missing or stale entry. `install.sh --with-delivery` prints both commands.
- `clean_finished.sh` and `reap_own.sh` gain `DRY_RUN` and `LEDGER`; `clean_finished.sh` gains `STRICT`, `IDLE_MIN`, `REAP_PATTERN`/`REAP_ALLOW`, a symlink-safe path check, a main-checkout guard, a full archive in place of the old patch-plus-names, and a guarded `SCRATCH` (fixed prefix, no globs, never a worktree or an ancestor, honours `DRY_RUN`); `reap_own.sh` gains an `ALLOW` argv allowlist and a pid-identity re-check.
- Operating discipline item 9, "Cleanup is scheduled, not remembered"; the cleanup loop template now points to the janitor as the preferred path.
