# Decision hygiene — structure the builder's own hard bet

**Read this when** the owner faces a hard, high-stakes call of their *own* —
a pivot, quitting or killing a line of work, a big irreversible spend, a
founder-level commitment — and wants it structured before they decide. This is
a *decision frame the parent runs with the owner*, not the adversarial gate the
rest of this skill runs on a proposal. It reuses the `kill-criteria` hat's
premortem; it does not restate it.

## Why this is separate from the hats

The three hats attack *a claim that something should be done* and return a
verdict (`HOLD` / `REVISE` / `PASS_TO_USER`); an agent-originated rec can be
withheld. A solo builder's pivot/quit/spend differs on two axes:

- **There is no board or co-founder** to check it. The usual safeguard —
  a second decision-maker — is absent, so the *structure* has to supply the
  friction the org chart normally would.
- **The decision is the owner's, and this frame never makes it.** The frame
  lays the bet out so the owner decides with less bias; it returns a structured
  decision, not a verdict, and never a fabricated probability.

## The frame

Run these in order. Record each step; hand the whole record to the owner.

### 1. Classify the door (reversibility)

- **Two-way door** — cheap and fast to reverse. Bias to *act*: decide quickly,
  cap the analysis, treat it as an experiment with a review date.
- **One-way door** — hard or impossible to reverse (shutting a product, a
  public commitment, unrecoverable spend, a data deletion). Slow down; the
  rest of this frame is mandatory, not optional.
- Most calls are two-way doors misread as one-way. State which it is, and
  *why*, before spending more rigor on it.

### 2. Take the outside view (reference class / base rate)

Before the inside story ("this time it works because…"), anchor on what
*comparable* bets actually did:

- Name the reference class honestly — be wary of a class picked to flatter.
- State the base-rate outcome for that class.
- Only then adjust for what is genuinely different here, and label that
  adjustment an assumption, not a fact.
- If no base rate is groundable, say so and mark the estimate `assumption`.
  Never invent a hit-rate or a market number to fill the slot.

### 3. Surface the biases actively

- **Sunk cost.** Money, time, and identity already spent are *gone* and do not
  belong in the forward decision. The question is never "have we put in too much
  to stop" — it is "would we start this today, knowing what we now know?"
- **Confirmation.** Write the single piece of evidence that would most change
  the call, then go look for it. A decision that cites only supporting evidence
  has not been tested.
- **Escalation of commitment.** A public or repeated prior "we're doing this"
  raises the felt cost of reversing. Name it so it stops steering silently.

### 4. Pre-commit the kill / quit / pivot criteria

Set the stop conditions *before* the bet, while judgment is cold — a call made
mid-loss reverses far worse than one set in advance:

- Write the specific, observable tripwires that will end or pivot the bet
  (a metric floor by a date, a spend ceiling, a runway line).
- Write what you will do when each fires — the pre-committed action, not
  "we'll reassess".
- Run the `kill-criteria` hat's **premortem** here (assume it already failed
  badly; write why) and extract the tripwires from that failure story. Do not
  restate the premortem procedure — it lives in the hat.

## What this frame returns

A structured decision record — door class, base rate (or a labeled
assumption), the biases named, the pre-committed tripwires — handed to the
owner. It does **not**:

- make the pivot / quit / spend call (that is the owner's),
- assert an ungroundable probability as fact (label it `assumption`), or
- fabricate a market size, hit-rate, or runway figure to complete the frame
  (route an unknowable number to the owner or to real research).

## Pitfalls

- **Deciding for the owner.** The frame structures; the owner chooses. A
  returned "you should pivot" is out of scope — return the structured bet.
- **A fabricated base rate.** An invented hit-rate is worse than none. Empty
  and labeled beats confident and made up.
- **Skipping the door classification.** One-way-door rigor on a cheap two-way
  call burns time; the reverse ships an irreversible mistake fast. Classify
  first.
- **Restating the premortem.** Point at the `kill-criteria` hat; do not
  duplicate it here.
